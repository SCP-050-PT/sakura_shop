# 🌸 Sakura Shop — Telegram-бот магазина

Бот-магазин на **aiogram 3**. Два раздела: цифровые товары со склада с автовыдачей и SMM-накрутка через панель с API v2 (soc-proof и совместимые). Есть баланс с пополнением через **CryptoBot** и **Telegram Stars**, рефералка, промокоды, поддержка и полноценная админ-панель внутри бота.

## Возможности

**Покупателю**
- 🛍 Каталог товаров: категории → подкатегории → покупка нужного количества, товар выдаётся сразу (текст или файл).
- 📈 Накрутка: выбор услуги → количество → ссылка, заказ уходит в SMM-панель. Если панель отменила заказ или выполнила его частично, деньги автоматически возвращаются на баланс.
- 💳 Пополнение: CryptoBot (счёт в рублях, оплата криптой) и Telegram Stars. Зачисление автоматическое.
- 👤 Профиль, история заказов, повторный показ купленного товара, статус накрутки.
- 🤝 Реферальная программа: процент от пополнений приглашённых.
- 🎁 Промокоды, 🆘 обращения в поддержку.

**Администратору** (`/admin` или кнопка в меню)
- 📊 Статистика: пользователи, пополнения, продажи, баланс SMM-панели.
- 🔎 Поиск пользователя по ID или @username: выдать или списать баланс, бонус % к пополнениям, бан.
- 🗂 Управление каталогом: категории, подкатегории, услуги, цены, описания, загрузка и очистка склада.
- 📮 Рассылка любого сообщения (текст, фото, видео) всем пользователям.
- 🎁 Создание промокодов, 🆘 ответы на обращения.

## Установка на Windows 10 + VS Code

1. Установите **Python 3.12** или новее с [python.org](https://www.python.org/downloads/windows/). В установщике обязательно отметьте **Add python.exe to PATH**.
2. Установите [VS Code](https://code.visualstudio.com/) и расширение **Python** от Microsoft. VS Code сам предложит его при открытии проекта.
3. Склонируйте репозиторий (`git clone ...`) или скачайте ZIP, затем откройте папку в VS Code: **File → Open Folder**.
4. Откройте терминал (**Terminal → New Terminal**) и выполните:

   ```powershell
   py -m venv .venv
   .venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   copy .env.example .env
   ```

   Если PowerShell пишет, что выполнение сценариев отключено, выполните один раз
   `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` и повторите активацию.

5. В VS Code выберите интерпретатор: `Ctrl+Shift+P` → **Python: Select Interpreter** → `.venv`.
6. Заполните `.env`. Минимум нужны `BOT_TOKEN` (получить у [@BotFather](https://t.me/BotFather)) и `ADMIN_IDS`, то есть ваш Telegram ID (его покажет [@userinfobot](https://t.me/userinfobot)).
7. Запуск: `python -m app` в терминале или **F5** (конфигурация «Запустить бота» уже есть в `.vscode/launch.json`).

База данных (SQLite, `data/shop.db`) создаётся автоматически при первом запуске.

## Настройка `.env`

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | Токен бота от @BotFather |
| `ADMIN_IDS` | ID админов через запятую |
| `SHOP_NAME` | Название магазина в сообщениях |
| `LOG_CHAT_ID` | Чат или канал для логов (покупки, пополнения, новые пользователи). Бот должен быть там админом. ID чата покажет команда `/id` |
| `SUPPORT_USERNAME` | Юзернейм для кнопки «Написать админу» |
| `REFERRAL_PERCENT` | Процент рефереру с каждого пополнения (по умолчанию 10) |
| `MIN_DEPOSIT_RUB` | Минимальная сумма пополнения |
| `SMM_API_URL`, `SMM_API_KEY` | Адрес и ключ SMM-панели (протокол API v2) |
| `CRYPTOBOT_TOKEN` | Токен Crypto Pay: [@CryptoBot](https://t.me/CryptoBot) → Crypto Pay → Create App |
| `CRYPTOBOT_TESTNET` | `true` — тестовая сеть ([@CryptoTestnetBot](https://t.me/CryptoTestnetBot)) |
| `STARS_RUB_RATE` | Сколько рублей зачислять за 1 ⭐️. `0` — Stars выключены |
| `DATABASE_URL` | Строка подключения к БД, по умолчанию SQLite |

Если способ оплаты не настроен, его кнопка просто не показывается.

> ⚠️ Никогда не коммитьте `.env` и файл базы: они уже в `.gitignore`.

## Как наполнить магазин

1. **Товары**: `/admin` → 🗂 Каталог → 📦 Товары → ➕ Категория → откройте её → ➕ Подкатегория. Формат: первая строка название, вторая цена, дальше описание.
2. Откройте подкатегорию → 📥 Загрузить товар. Каждая строка становится единицей товара (например `login:password`). Для многострочного товара разделяйте единицы строкой `---`. Файлы отправляйте документами: каждый файл тоже единица товара.
3. **Накрутка**: 🗂 Каталог → 📈 Накрутка → категория → подкатегория → ➕ Услуга. Укажите название, **ID услуги в панели**, цену за 1000, минимум и максимум. ID и закупочные цены берутся из списка услуг вашей SMM-панели.

## Структура проекта

```
app/
  __main__.py          точка входа: python -m app
  config.py            настройки из .env (pydantic-settings)
  money.py             деньги хранятся в копейках (int)
  background.py        фоновые проверки: оплаты CryptoBot, статусы накрутки
  db/                  модели SQLAlchemy 2 и подключение к БД
  services/
    shop.py            бизнес-логика: покупки, платежи, промокоды, поддержка
    smm_api.py         клиент SMM-панели (httpx)
    cryptobot.py       клиент Crypto Pay API (httpx)
  bot/
    handlers/          хендлеры: пользователь и админка
    keyboards.py       клавиатуры
    callbacks.py       типизированные callback-данные
    middlewares.py     сессия БД, регистрация пользователя, антифлуд
tests/                 тесты (pytest)
```

## Тесты

```powershell

```

Тесты прогоняют реальные сценарии через диспетчер aiogram с подменённым Telegram API: старт с рефералкой, создание каталога админом, покупку, пополнение звёздами и через CryptoBot, заказ накрутки с возвратом и поддержку.

## Чем отличается от исходного скрипта

- aiogram 2 → **aiogram 3**, синхронный `requests` → асинхронный **httpx**, сырые SQL-кортежи → **SQLAlchemy 2**.
- QIWI (не работает с 2024 года) заменён на CryptoBot и Telegram Stars.
- Исправлены баги с деньгами. Пополнение больше не засчитывается дважды, бонус пользователя не прибавляется к сумме платежа как рубли, а покупка и списание выполняются атомарно, без ухода в минус при двойном нажатии.
- Секреты только в `.env`, база не хранится в репозитории.
- Старая база `db.db` несовместима с новой схемой: каталог нужно завести заново через админку.

## Запуск на сервере (кратко)

На VPS с Linux: `python3 -m venv .venv && .venv/bin/pip install -r requirements.txt`, заполните `.env` и запустите `python -m app` через systemd или `screen`. Если нагрузка большая, укажите PostgreSQL в `DATABASE_URL` (`postgresql+asyncpg://...`, плюс `pip install asyncpg`).
